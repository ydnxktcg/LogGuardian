Research project

LogGuardian

Context-aware secret detection for GitHub Actions build logs, combining rule-based scanners with machine learning to separate exposed secrets from benign values.

View source code ↗ Download dataset ↓

Approach

From raw logs to context-aware decisions

LogGuardian uses a three-stage pipeline to identify candidate secrets, recover their surrounding context, and classify them.

01

Candidate discovery

Gitleaks, TruffleHog, and custom regular expressions identify potentially sensitive values.

02

Context construction

Nearby log lines are collected to preserve the execution context surrounding each candidate.

03

Secret classification

A context-aware machine learning model distinguishes true secrets from benign values.
